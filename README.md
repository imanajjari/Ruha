# RUHA — برنامه‌ریز و یادآور شخصی

RUHA یک PWA فارسی، راست‌چین و واکنش‌گرا برای مدیریت کارها، یادآورها و یادداشت‌هاست. نسخه‌ی فعلی با اولویت استفاده‌ی محلی ساخته شده تا بدون حساب و بدون اینترنت هم کار کند. پوشه‌ی Django نیز برای API چندکاربره و زیرساخت Push ارائه شده است.

## اجرای سریع رابط برنامه

**بدون نصب کتابخانه یا Node.js:**

- ویندوز: روی `run-local.bat` دوبار کلیک کن.
- لینوکس/macOS: در ترمینال، داخل پوشه‌ی پروژه اجرا کن:

```bash
python3 -m http.server 8000
```

سپس در مرورگر `http://127.0.0.1:8000` را باز کن. آدرس `localhost` برای تست اعلان‌ها و قابلیت‌های مرورگر معمولاً به‌عنوان secure context محلی پذیرفته می‌شود. برای میکروفون/دوربین و نصب واقعی PWA در محیط انتشار، HTTPS لازم است.

## امکانات پیاده‌سازی‌شده در رابط فعلی

- طراحی فارسی و RTL، واکنش‌گرا برای موبایل، تبلت و دسکتاپ؛ نوار پایین موبایل و منوی دسکتاپ.
- تم روشن/تیره/خودکار، تاریخ شمسی و میلادی برای نمایش، شروع هفته قابل انتخاب.
- ثبت کار، یادآور و یادداشت؛ دسته، اولویت، شرح، مدت تخمینی، تکرار پایه و وضعیت.
- ذخیره‌ی خودکار در IndexedDB با fallback به localStorage؛ اطلاعات و پیوست‌ها روی همان مرورگر می‌مانند.
- نصب PWA، کش پوسته‌ی اصلی، دسترسی آفلاین پس از اولین بازدید آنلاین.
- اعلان مرورگر و بررسی یادآورها در زمان باز بودن برنامه؛ ساعت سکوت و تعویق ۱۰ دقیقه‌ای.
- زیرساخت Service Worker برای دریافت Web Push و دکمه‌های «انجام شد» / «۱۰ دقیقه بعد».
- تایم‌لاین روزانه و جابه‌جایی بلوک کارها با Drag & Drop.
- تقویم ماهانه/هفتگی با انتخاب روز و نمایش هم‌زمان تاریخ دوم.
- زمان‌سنج تمرکز و گزارش ساده‌ی پیشرفت، زمان ثبت‌شده و هیت‌مپ فعالیت.
- افزودن عکس و ضبط/پخش ویس در مرورگرهای سازگار؛ فشرده‌سازی اولیه‌ی عکس.
- جست‌وجوی عنوان/شرح با نرمال‌سازی حروف فارسی، فیلتر، آرشیو، سطل زباله، Undo.
- پشتیبان JSON، خروجی CSV و ICS، واردکردن JSON.

## راه‌اندازی Django + PostgreSQL

پیش‌نیاز: Python 3.12+ برای اجرای محلی (یا Docker برای اجرای یکپارچه).

### اجرای محلی با SQLite

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python manage.py makemigrations core
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

سپس `http://127.0.0.1:8000` را باز کن. API با پیشوند `/api/v1/` است. مسیرهای اصلی در `apps/core/urls.py` آمده‌اند.

### اجرای با Docker Compose

```bash
cp .env.example .env
# برای محیط واقعی، DJANGO_SECRET_KEY و DB_PASSWORD را عوض کن.
docker compose up --build
```

در ویندوز می‌توان فایل `.env.example` را به `.env` کپی کرد و سپس `docker compose up --build` اجرا کرد. پنل Django admin در `/admin/` است. برای ساخت حساب مدیریت، در ترمینال دوم اجرا کن:

```bash
docker compose exec app python manage.py createsuperuser
```

## API بک‌اند

- `POST /api/v1/auth/register`, `POST /api/v1/auth/login`, `POST /api/v1/auth/logout`, `GET /api/v1/auth/me`
- `GET/POST /api/v1/items`, `GET/PATCH/DELETE /api/v1/items/{uuid}`
- `POST /api/v1/items/{uuid}/complete`, `POST /api/v1/items/{uuid}/snooze`
- `GET/POST /api/v1/categories`
- `POST /api/v1/items/{uuid}/attachments`, `GET /api/v1/attachments/{uuid}` (دانلود پیوست فقط پس از احراز هویت و مالکیت آیتم)
- `POST /api/v1/timer/start`, `POST /api/v1/timer/stop`, `GET/POST /api/v1/time-entries`
- `GET /api/v1/stats/progress`, `GET /api/v1/stats/time-spent`
- `POST /api/v1/push/subscribe`, `POST /api/v1/push/unsubscribe`, `GET /api/v1/export`

API به نشست Django و مجوزدهی کاربر متکی است؛ Queryها با کاربر جاری محدود می‌شوند. رمز عبور با Argon2 هش می‌شود. فایل‌های بارگذاری‌شده از مسیر عمومی سرو نمی‌شوند.

## تنظیم Web Push برای اعلان در زمان بسته بودن برنامه

اعلان‌های محلی در رابط فعلی، موعد یادآورها را وقتی صفحه اجراست بررسی می‌کنند. مرورگرهای وب اجازه نمی‌دهند صفحه‌ی بسته‌شده به‌طور قابل اتکا تایمر اجرا کند. برای اعلان واقعی در پس‌زمینه، باید برنامه روی HTTPS منتشر شود، VAPID key pair ساخته و در `.env` با `VAPID_PUBLIC_KEY` و `VAPID_PRIVATE_KEY` تنظیم شود، سپس کلاینت پس از ورود کاربر با `PushManager.subscribe()` اشتراک بسازد و آن را به `/api/v1/push/subscribe` بفرستد. حلقه‌ی زمان‌بندی باید با کران دوره‌ای اجرا شود:

```bash
python manage.py send_due_reminders
```

برای تولید، این فرمان را با cron یا یک worker زمان‌بندی کن؛ در حال حاضر اجرای push server و API آماده‌ی اتصال است، اما فرانت‌اند این نسخه هنوز حساب/همگام‌سازی و ثبت اشتراک Push را به‌صورت کامل به API متصل نمی‌کند. اعلان‌های مرورگر در نسخه‌ی فعلی هنگام باز بودن برنامه فعال‌اند.

## نکات شفاف نسخه‌ی فعلی

- این خروجی یک MVP کاربردی و کد پایه‌ی توسعه است، نه محصول نهاییِ آماده‌ی استفاده‌ی عمومی برای ۱۰٬۰۰۰ کاربر.
- داده‌های رابط در یک مرورگر ذخیره می‌شوند؛ همگام‌سازی بین دستگاه‌ها و ورود/ثبت‌نام از UI هنوز تکمیل نشده است، با اینکه API اولیه‌ی Django پیاده شده.
- تکرارهای ساده در رابط پیاده شده‌اند. تکرار پیشرفته‌ی شمسی، حل تعارض همگام‌سازی، share link عمومی، ایمیل جایگزین، OCR و رونویسی ویس هنوز در دامنه‌ی این MVP نیستند.
- برای استقرار عمومی، HTTPS، تنظیم اسرار، پشتیبان‌گیری، تست نفوذ/بازبینی امنیتی، محدودیت فایل و ساخت migrationهای نسخه‌بندی‌شده لازم است.
